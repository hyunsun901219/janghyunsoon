# 안내 시트 검토 결과

## 꼭 고칠 부분
1. **코드 문자 중복**
   - 빈도 `R`(매일) ↔ 역할 `R`(Responsible)
   - 빈도 `S`(비정기) ↔ 영향력 `S1~S3`
   - 제안: 빈도를 `D / W / M / Q / P / N`으로 변경
2. **코드 가이드 번호가 ③④만 있음** → ① 수행 주기 ② 역할 ③ 사고 복잡도 ④ 영향력으로 통일
3. **"5~8개"가 업무·영역 두 곳에 쓰임** → "영역 2~4개, 전체 업무 5~8개"로 계층 명확화
4. `**합계가 100%**` 별표가 엑셀에서 그대로 보임 → 별표 지우고 셀 서식으로 굵게

## 다듬을 부분
- R/A 동시 해당 시 `R/A` 표기 안내 추가
- 비중% 기준 명시 (예: 연간 투입 시간)
- IT 예시 `mAX 운영`은 설명 추가, `일반 업무`는 모호하니 변경
- 구매 예시 `개발/전략/정보` 구체화
- 기획 `긴급 대응`은 영역보다 빈도에 가까움
- Q에 연간 포함 → 필요시 `Y` 분리
- 복합 코드는 "주된 주기 1개만"으로 단순화 권장
- "시트 3·4" 대신 시트 이름으로 지칭
- 응답 열람 범위(HR팀만 열람 등) 문구 추가

## 수정 코드 가이드 예시
```
① 수행 주기   D 일간 / W 주간 / M 월간 / Q 분기·연간 / P 프로젝트 / N 비정기·지원
② 역할        R 실행자 / A 최종 책임자 / R/A 직접 수행 + 최종 책임
③ 사고 복잡도 T1 절차 처리 / T2 상황 판단 / T3 방법·정책 설계
④ 영향력      S1 본인·라인 / S2 실·팀 / S3 그룹·전사

예) 월결산 마감 | M | R/A | T1 | S2 | 25%
```
