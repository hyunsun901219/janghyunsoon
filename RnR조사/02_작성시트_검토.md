# 작성용 시트 + 샘플 검토 결과

## 꼭 고칠 부분
1. **업무 개수 안내 모순**: C 섹션은 5~8행인데 코드 가이드는 "영역 5~8개 × 영역당 3~5개"(=15~40개)
   → "업무 영역 2~4개, 전체 업무 5~8개"로 수정
2. **코드 중복 그대로** (빈도 R/S ↔ 역할 R, 영향력 S). 용어도 "S 돌발" vs 안내 시트 "S 비정기·지원" 불일치
3. **예시 행이 1번 입력 행을 차지** → 합계 15%로 보임. 예시는 표 위 회색 행으로 분리, 합계 제외
4. **예시 내용이 기준 위반**: 영역 "보고"(불명확), 상세 행동 "다운로드"(지나치게 세부)
5. **내부 메모 삭제**: 노란 강조, 검은 상자 절차 메모는 배포 전 제거

## 드롭다운 방식
- 선택만 가능하게 막으면 중복·공백 업무가 누락됨
- 목록 끝에 **"기타(직접 입력)"** 추가, 유효성 검사 오류 스타일을 **'경고'**로

## 다듬을 부분
- 코드 열(빈도·비중·역할·복잡도·영향력)을 붙이고, 협업·KPI는 뒤로
- 빈도/역할/복잡도/영향력/소속에 드롭다운
- 비중% 0~100% 제한 + 합계≠100% 시 빨간색 조건부 서식
- 협업 대상은 실/팀 이름으로
- D2·D3는 필수 권장 (중복·공백 파악 핵심)
- E 역량 자가평가·E4 직급 적정성은 "인사평가 무관" 문구와 충돌 → 분리 또는 활용 범위 명시

## 샘플에서 따라 하지 말 것
- 샘플 ① #6 "ERP 회계 모듈 운영 지원": 역할 `A`로 적었지만 상세 행동은 직접 처리 → `R`이 맞음
- 샘플 ② #7 KPI "—" 빈칸 → 예: "R&R 조정안 확정 건수"
- 샘플 ② #6 "즉시대응": D1에 "매일 발생"이라 했는데 빈도는 `S` → 기준 혼동 소지
